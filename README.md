# QUADLY

**Your Campus. One Connected Space.**

QUADLY is a private campus platform designed for students, teachers, and staff of a single college.

Instead of juggling notice boards, WhatsApp groups, scattered PDFs, and multiple portals, QUADLY brings everything together in one place.

### Core Features

- **Home:** Campus map, student status, and help desk.
- **Passport:** Student profile and academic information.
- **Cadence:** Class schedules, calendar, and important events.
- **Vault:** Important documents, notes, and resources.
- **Huddle:** Campus communication and collaboration.

### Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- React Router
- Lucide React
